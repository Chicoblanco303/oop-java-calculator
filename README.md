
# OOP Java Calculator

A console-based calculator developed in Java using object-oriented programming principles.

## Features
- Addition, subtraction, multiplication, and division
- Square root calculations
- Exponentiation
- Input validation
- Division-by-zero protection
- Error handling for negative square roots
- Menu-driven interface

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Java Scanner
- Exception Handling

## Project Structure

- `Main.java` — application entry point, calculator logic, and arithmetic operations.

## How to Run

### Using OneCompiler
1. Open OneCompiler's Java editor.
2. Paste the contents of `Main.java`.
3. Click Run.
4. Enter a menu choice from 1 to 7.
5. Follow the prompts to perform a calculation.

### Using a local Java installation
1. Install a compatible Java Development Kit.
2. Open a terminal in the directory containing `Main.java`.
3. Compile the program:

```bash
javac Main.java
```

4. Run the program:

```bash
java Main
```

## OOP Concepts Demonstrated
- Classes and objects
- Encapsulation through private fields and methods
- Methods and method calls
- Separation of calculation logic from user interaction
- Exception handling

## Learning Goals
Practice Java programming, object-oriented design, user input, arithmetic operations, and error handling.
